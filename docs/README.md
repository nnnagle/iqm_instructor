# Planning documents

Living reference for instructors, TAs, and future agents. These describe the
*intent* of the course; they are **not** student-facing lab instructions.

- **`GEOG415_Lab_Sequence_Instructor_Semester_Map.md`** — session-by-session
  map: for each lab, what to assume students know, what the session must
  accomplish, and what should exist when they leave. One graded deliverable per
  module.
- **`geog415_semester_rating_project_plan.md`** — the design document: the
  cumulative Community Primary Care Priority Rating project, the six-module
  architecture, the twelve-lab sequence, data sources, and the constraints on
  what the course should *not* become.

These Markdown files were converted from the original Word documents; the
`.docx` remain the authored source of record.

When these change, the build in this repo should follow them — not the reverse.
